# Documentação do ACCENTRA

Material para a documentação do ERP. Cada ficheiro aqui explica **uma coisa e
porquê** — a regra, a decisão, e o erro que a decisão evita. O `HANDOFF.md` na
raiz é o histórico versão a versão; isto é o oposto: o estado actual, sem
cronologia.

## O que NÃO entra aqui

Este repositório é **público**. Não entram dados de clientes, salários,
números de PPS, nem documentos pessoais — nem como exemplo. Quando um documento
precisa de um caso real para se explicar, descreve-se o método e o resultado sem
reproduzir o original.
